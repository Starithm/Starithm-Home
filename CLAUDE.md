# Starithm Home — design system

Read this before writing or changing any UI. It exists because the circulars-archive page
was built with its own 25-constant palette (`#08080b` ground, `#a855f7` accent) while the
brand is `#0E0B16` / `#8D0FF5`. Nothing caught it for weeks. The rules below are what
stops that recurring.

Run `npm run check:design` before you finish. It fails the build on token drift and on new
raw hex.

---

## Colour: use a token, never a hex

116 custom properties are defined but only ~51 are referenced. Most of the rest are
machine-generated. Reach for these families and ignore the others:

| Family | Use for | Example |
|---|---|---|
| `--background` `--foreground` | page ground, primary text | `background: var(--background)` |
| `--surface` `--surface-raised` `--surface-sunken` | elevation; higher = lighter | card sits on `--surface` |
| `--line-hairline` `--line-subtle` `--line-control` `--line-dialog` `--line-hover` | borders, rules, dividers | `1px solid var(--line-hairline)` |
| `--text-body` `--text-secondary` `--text-raw` `--text-muted` `--text-faint` `--text-placeholder` `--text-disabled` | the text ramp, most→least prominent | `color: var(--text-muted)` |
| `--primary` `--accent-text` `--accent-surface` `--accent-border` | brand violet; `--primary` for fills/borders, `--accent-text` when accent is *text* | see contrast note below |
| `--starithm-*` | named brand colours | `--starithm-electric-violet` |
| `--font-mono` `--font-prose` `--font-display` `--measure` | type roles, line length | below |

**Ignore these** — they are not for component code:
- `--color-*` — mirrors generated by Tailwind's `@theme inline` block. Zero `var()` usages.
  They back utility classes; never reference them directly.
- `--rdp-*` — react-day-picker internals.

Tokens are defined once, in `shared/styles/globals.css`. `:root` holds the **dark** defaults
(the app boots dark); `.light` is the only override. There is deliberately no `.dark` block —
it would duplicate `:root` exactly, which is how `ring` silently drifted.

`shared/theme/theme.ts` is a **bridge, not a second source**. It mirrors globals.css for the
519 legacy `getThemeValue()` call sites, which need literal values because several
string-concatenate hex alpha (`${violet}1A`). `var(--x)1A` is invalid CSS, so those sites
cannot consume tokens. `npm run check:tokens` fails if the two disagree.

### Contrast, non-negotiable
- Body text ≥ **4.5:1** against its ground. `--text-muted` is the floor at 5.91:1 dark / 5.85:1 light.
- UI boundaries (chip borders, focus rings) ≥ **3:1**. `--primary` on `--background` is 3.26:1 —
  it clears, but only just. Do not put `--primary` on a lighter ground without rechecking.
- `--primary` (#8D0FF5) is 92% saturation. Use `--accent-text` (#CA90FA, 8.24:1) when the
  accent is *text*; reserve `--primary` for fills, borders and marks.

## Type: two roles, and they are not interchangeable

- `var(--font-mono)` — **Google Sans Code**. Identifiers, measurements, tables, timestamps,
  anything that must align. Has tabular figures.
- `var(--font-prose)` — **Andika**. Multi-sentence text: AI summaries, circular body copy.
  Weights 400/700 only, **no medium**. No tabular figures — never use it on numeric columns.
- `var(--font-display)` — Newsreader, serif. Homepage hero only.

Prose gets `max-width: var(--measure)` (60ch). **`ch` is the advance of "0", not the average
character** — in a monospace those are identical, but in Andika "0" is 0.586em against a
0.492em average, so `68ch` rendered ~81 characters. 60ch lands at ~71. A mono block needing a
measure needs its own number; one `ch` value cannot serve both.

Do **not** size Andika up to "match" the mono: their x-heights are 0.508 vs 0.523em, so at the
same px they are already optically matched.

Never declare a font that isn't loaded. `index.html` loads exactly three families. The archive
declared `'JetBrains Mono'` for months and silently fell back.

## Components: check `shared/` before writing a new styled-component

`shared/components/ui/primitives.tsx` — `Page` `Column` `HeaderRow` `Title` `Subtitle`
`Eyebrow` `Section` `Row` `EmptyState` `Overlay` `TableWrap` `TabRow` `Tab` `Rule`.
All token-based, exported from `@shared/components`.

Extend rather than redraw: ``styled(Page)` font-family: var(--font-mono); ` ``.

`shared/components/ui/` also holds 13 kept shadcn primitives (`badge` `button` `calendar`
`card` `celestial-sphere` `dialog` `error` `input` `label` `loading` `select` `sheet`
`tooltip`). **37 unused ones were deleted** — don't reintroduce one without a real consumer;
the original drop-in left 39 of 52 with none, and removing them cut emitted CSS 195 → 104 kB.

There is **no toast system**. `toast`, `toaster` and `use-toast` were retired with the
standalone MFE builds — don't call one.

`Page` is still defined 8 separate times across the repo, `Title` 6, `HeaderRow` 5. Adoption
is incomplete — when you touch a styled module, migrate its shapes to the primitives rather
than adding another copy.

## Guards

| Command | Catches |
|---|---|
| `npm run check:tokens` | `theme.ts` drifting from `globals.css` |
| `npm run check:no-raw-hex` | new raw hex in components — a **ratchet**: 577 literals already exist, it fails only on an increase. Re-baseline with `-- --update` after a genuine reduction |
| `npm run check:design` | both |
| `npx tsc --noEmit` | ~116 pre-existing errors (root tsconfig doesn't map the vite aliases). Diff against a baseline; don't expect zero |

`npm run build` is the shell only. The deploy runs `npm run install:all && npm run build:all` —
use that when changing anything that touches packaging, or you will miss module-resolution
failures entirely.
